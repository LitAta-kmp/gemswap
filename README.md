# GemSwap

Match-3 puzzle game with a timed solo mode and a turn-based battle mode against an NPC.
Built with Kotlin Multiplatform and Compose Multiplatform (Android target).

## Features

**Solo mode**
- 8x8 board, 5 tile types with distinct shapes and colors
- Drag a tile onto a neighbor to swap
- Animated gravity and refill, chain-reaction cascades with a score multiplier
- Shake feedback on invalid swaps, combo indicator, per-color counters
- 90-second round, top-10 leaderboard stored locally

**Battle mode (vs NPC)**
- Turn-based on a single shared board, 15-second turn timer
- Skull tiles deal damage, heal tiles restore HP
- Extra turn for a run of 4+ same-colored tiles (including runs from cascades)
- Activatable "skull-clear" ability that costs 10 green tiles
- NPC picks the best available swap (damage first, heal when hurt)

**Robustness**
- The board is regenerated if no valid move remains (deadlock detection)

## Tech stack

- Kotlin Multiplatform, Compose Multiplatform
- Navigation Compose with type-safe routes (kotlinx-serialization)
- Koin for dependency injection
- SQLDelight for local score history
- Coroutines, StateFlow / SharedFlow
- Unit tests for the reducer

## Architecture

Three layers with the dependency pointing inward:

- `domain`: pure Kotlin game logic (Board, MatchFinder, SwapValidator, CascadeResolver, NpcMoveSelector, repository interfaces). No Compose, no Android.
- `data`: SQLDelight implementation of the history repository.
- `presentation`: MVI (state, intent, side effect), ViewModels, Compose UI, navigation.

The reducers are pure functions and serve as the tested specification of game rules.
At runtime the ViewModels resolve cascades step by step with delays so that
animations can play between steps.

## Project structure

    shared/src/commonMain/kotlin/org/example/gemswap/
    ├── domain/        # game logic and repository interfaces
    ├── data/local/    # SQLDelight repository
    ├── presentation/  # ViewModels, reducers, navigation, UI
    └── di/            # Koin modules

## Run

Open the project in Android Studio and run the `androidApp` configuration,
or build a debug APK:

    ./gradlew :androidApp:assembleDebug

Run unit tests:

    ./gradlew :shared:testAndroidHostTest

## Status

- Android: tested on emulator and a physical device.
- iOS: the project structure was generated by the KMP wizard, but the iOS target
  has not been built or tested.
